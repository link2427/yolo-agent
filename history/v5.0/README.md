# yolo-dev 5.0 — partial recovery

The complete 5.0 source tree was not present in the recovered workspace, so
this is deliberately **not** represented as a reproducible source release.

What survived:

- operator documentation;
- the Container Forge build log;
- the export manifest and loading instructions; and
- SHA-256 for the excluded 1.65 GiB Docker archive.

The archive itself remains on the read-only recovery volume and is not stored
in GitHub. Use these files for provenance and comparison, not as a promise that
5.0 can be rebuilt byte-for-byte.
