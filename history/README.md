# Recovered history

This directory records artifacts recovered from the August 18, 2026 backup.
Large Docker archives and skill-library ZIP files are intentionally excluded
from Git; their checksums and manifests are retained instead.

- `v5.0/`: partial historical evidence. The original build context did not survive.
- `v6.0/`: export metadata for the source preserved by tag `v6.0.0-recovered`.

The original recovery copy remains outside this repository. Nothing in this
directory contains Coder session logs, model transcripts, runtime `.env`
files, API keys, or Git credentials.
